# うわさの育て方

小さな話が、世界の法則になる。架空の街で伝聞を育てるクリッカー＋放置ゲーム。

現在はPhase 8です。追加ミニゲーム「夜便の仕分け」、絵葉書6枚の収集、任意のエピローグ「こだま街の年代記」を実装しました。設計は[ゲームデザイン](docs/DESIGN.md)、変更履歴は[CHANGELOG](docs/CHANGELOG.md)、保存方式は[セーブ仕様](docs/SAVE.md)、進行測定は[バランス検証](docs/BALANCE.md)を参照してください。

## 開発

Node.js 20.19以上とnpmを使用し、このファイルのあるディレクトリで実行します。

```sh
npm ci
npm run dev
```

## 検証・静的配信

```sh
npm run build
npm test
npm run simulate
npm run simulate:phase4
npm run simulate:phase5
npm run simulate:phase6
npm run simulate:phase8
npm run preview
```

buildはstrict TypeScriptの型検査後、dist/へ静的ファイルを出力します。testはVitestを1回実行して終了します。配信先のフォルダ名に依存しないよう、baseとアセット参照は相対パスです。公開はリポジトリ共通のワークフローが担当します。

UI文言はsrc/i18n/ja.ts、経済数値はsrc/data/以下に集約しています。巨大数はbreak_eternity.jsで計算します。画像はpublic/assets/に同梱し、外部フォント・外部APIは使用していません。画像の生成指定は[ASSETS](docs/ASSETS.md)を参照してください。

設定では配色（夜／昼／端末）、演出、効果音、音量、自動セーブ間隔（15／30／60秒）を変更できます。音は初期OFFで、ONにした後の操作から鳴ります。端末の「動きを減らす」設定も尊重します。長いオフライン復帰は進捗を表示し、計算中は操作を止めて描画へ定期的に制御を返します。

8時間復帰の測定は、`npm run simulate:phase6`で正規の進行記録を生成した後、`node scripts/run-phase7.mjs`で再現できます。出力はartifacts/（Git対象外）です。

Phase 8の測定もsimulate:phase6で生成した神話3編の正規記録を続けて使用します。simulate:phase8は試練3種、既存の挿絵、夜便6枚とエピローグへの到達・支出・保存整合性を確認し、画面確認用の記録をartifacts/へ出力します。

## 遊び方と記録

- 掲示板の「そっと、ささやく」で伝聞を獲得。ボタンにフォーカスしてEnter・Spaceでも操作できます。
- 10伝聞で最初の仲間を迎えると自動生産が始まります。価格は購入数に応じて1.15倍ずつ上がります。
- 次の生産者は、前の生産者を迎え、累計伝聞の条件を満たすと表示されます。
- 研究は生産者の所有数や累計伝聞で解放されます。同じ生産者の研究倍率は乗算し、クリック研究の基礎値は加算します。
- 実績を達成するたび、生産と基礎クリックへ0.5%ずつ加算ボーナス。初回の購入・研究前だけは、実績が増えても1クリック＝厳密に1伝聞です。隠し実績もあります。
- 累計5,000伝聞で「耳寄りな話」が出現するようになります。90〜150秒の待ち時間の後、15秒間だけ回収可能。回収すると30秒間の生産が3倍になり、基礎クリックにも倍率が付きます。
- 研究・実績・統計は順にタブが現れます。スマホ幅では画面下のタブで切り替えます。
- 「遊び方」タブは開始時から読めます。PCは全タブの位置を揃え、仲間の1組あたりの生産、研究の効果・条件をメインでも常時表示します。購入可能なボタンは塗りつぶしと実線枠、不可能なものは点線枠で区別します。購入済みの研究は「研究」タブへ残します。
- 全画面下部に制作クレジットがあり、「制作者」タブで制作の役割を紹介します。メインの「SNS共有」で文章のコピーとPNG記録カードの保存ができます。「Xでツイート」は現在の伝聞数を入れた投稿画面を開きます。画像を添える場合は保存したPNGを選んでください。対応端末では共有先選択にも渡せます。ローカル試遊のURLは共有内容に含めません。詳細は[共有機能](docs/SHARING.md)を参照。
- 今回の累計が100万に届くと伝説化の予告が現れ、10京で語り草1以上を得て転生できます。報酬・次の目標・持ち越し範囲を確認して実行します。
- 語り草累計1ごとに、生産と基礎クリックへ10%ずつの加算ボーナス。語り草を永続研究に使っても、この累計ボーナスは減りません。
- 転生では通常の生産者・研究・一時効果をリセットし、実績・生涯記録・語り草・永続研究を保持します。初回はボット測定で約46〜57分。人の操作によって変わります。
- 「語りの引き継ぎ」の無料5組は、次の転生から適用され、価格上昇の購入数には含めません。
- 購入数は×1・×10・×100・最大から選択。固定数購入は、その全数分を払える場合だけ実行します。
- 「設定と記録」で日本語・英語・指数表記を切り替え、手動セーブできます。30秒ごと・タブ離脱時・ページ終了時にも保存します。
- 記録はブラウザのlocalStorageに保存し、直近3世代を保持します。再読み込みや復帰時には、直接生産の経過を最大8時間反映します。
- 保存不可・破損・別タブとの競合は画面下へ通知します。復元不能な既存データは上書きしません。競合時は他のタブを閉じ、残したい記録のあるタブを再読み込みしてください。

「設定と記録」から、セーブ文字列の書き出し・コピー・読み込み、ファイルの入出力、バックアップ復元、二重確認付きリセットを利用できます。圧縮・署名付きのv6形式を使い、v1・署名付きv2／v3／v4／v5を自動移行します。構造が正常な改ざんデータは「改造データ」として読み込めます。破損データは拒否します。外部から読む署名のない旧形式には改造印が付きます。

署名にはWeb Crypto、圧縮にはブラウザ標準APIを使います。HTTPSまたはlocalhostの対応ブラウザで利用してください。終了時は直近の準備済み署名を保存するため、直前の操作を確実に残すときは手動セーブの完了を確認してください。階層型生産・神話編纂・試練・自動化も利用できます。

## 寄り道「話のつぎほ」

今回の累計50,000伝聞で解放。伝聞（一時効果を除く生産10秒分、最低1,000）と取材券1枚を使って始めます。10秒ごとの各段階で堅実90%／大胆60%を選び、成功後は持ち帰るか続けるかを判断します。最大3段階、失敗すると今回のポイントをすべて失います。

持ち帰ったポイント×10秒の直接生産2倍が報酬で、最大60秒。クリックには適用せず、耳寄りな話との合成は最大6倍です。6ポイントの持ち帰りで挿絵帳を解放します。取材券は初回3枚、15分ごとに1枚回復、上限3枚。再読み込みでも同じ話へ戻り、留守中は進行中の1段階まで完了して選択を待ちます。

取材券・回復・挿絵・生涯成績は伝説化後も保持します。進行中の話・報酬ブーストは伝説化でリセットし、次の周回でも累計50,000に届くまで新規プレイできません。
## 連鎖伝播・神話と街の法則

20語り草で「連鎖伝播」を研究すると、上位の語り手が購入済みの隣接する下位を毎秒0.001ずつ生みます。生成数は生産へ使いますが、価格上昇・研究・所有数実績には含めません。生成を受ける段は、その周回で1組以上の購入が必要です。無料の開始仲間だけでは生成を受けません。

語り草累計100と今回の累計1兆で、神話を1編編纂できます。周回・語り草・永続研究をリセットし、神話1編ごとの1.5倍と新しい法則を得ます。実績・生涯記録・図鑑・試練報酬・自動化設定は残ります。

神話1編で試練と自動購入、2編で自動研究、3編で自動伝説化を解放します。自動化は初期OFF。対象・優先順・最低保持伝聞・語り草しきい値を設定できます。自動購入と研究は1秒ごとに処理し、留守中も反映します。自動伝説化はオンライン時だけです。

試練は「無言の街」「閉じた路地」「夢のない夜」の3種類。各累計1,000万でクリアし、初回のみ永続1.1倍。語り草は0です。「無言の街」は引き継ぎ研究が必要で、5組から開始します。試練中は通常の伝説化・神話編纂・自動伝説化を停止します。

## 夜便と年代記

神話1編と今回の累計50,000伝聞で「夜便の仕分け」が利用可能になります。伝聞と配達券1枚を使い、手掛かりから3通の宛先を選びます。1通10秒、2問以上正解で絵葉書を1枚獲得。6枚は重複なくそろい、報酬で主通貨や生産倍率は増えません。配達券は初回3枚、15分で1枚回復、上限3枚です。

神話3編・試練3種のクリア・つぎほの6ポイント挿絵・絵葉書6枚で「こだま街の年代記」の最後のページが開きます。任意の一区切りとして保存し、その後も購入・転生・寄り道を続けられます。既存の保存v1〜v7はv8へ移行します。
