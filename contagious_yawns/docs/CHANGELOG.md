## Phase 2 — セーブ完成（2026-10-28）

- セーブ形式 `akubi|v2|<本体>|<署名>`。本体は JSON の UTF-8 を Base64URL（圧縮なし：DESIGN.md §13）。
  署名は Web Crypto の HMAC-SHA256 の先頭16バイトで、「ゲームID|版|本体」全体にかける。鍵は分割・並べ替え・XOR して埋め込み。

- 整合性チェック：手持ち≦累計、手持ち＋生産者に使った額≦累計、累計がクリック数とプレイ時間×生産量から見て多すぎないか、クリック数がプレイ時間に対して多すぎないか、最終セーブ時刻が未来でないか、作成時刻≦最終セーブ時刻。
  署名不一致か矛盾があれば読み込みは許して `tainted` を立て、上部に「改造データ」バッジを出す（統計画面ができたらそちらにも出す）。
