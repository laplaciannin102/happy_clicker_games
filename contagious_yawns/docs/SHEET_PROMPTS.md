# SHEET_PROMPTS — ChatGPT に貼るプロンプト集

`npm run images:prompts` で `scripts/sheets.ts` から作ったファイルです。手で直さず、直すときは `scripts/sheets.ts` を直して作り直します。
使い方は docs/ASSETS.md の「ChatGPT でまとめて作る」を見てください。

## 1. sheet1（12個）→ `art/raw/sheets/sheet1.png` に保存

```
Create ONE image: a sprite sheet of 12 separate game icons on an invisible grid of 4 columns x 3 rows. Landscape 3:2 (1536x1024).

STYLE for every icon: soft pastel night-sky palette (lavender #8b7bd8, pale violet, cream yellow, misty blue), cute sleepy mood, rounded chunky shapes, thick soft outlines in dark indigo, flat shading with one gentle highlight, readable at 32x32 pixels, consistent sticker-like game icons.

LAYOUT RULES:
- Each icon is centered in its own cell and fills about 70% of the cell.
- Leave clear empty space between icons. Icons must never touch or overlap each other.
- All icons are about the same size and drawn in exactly the same style.
- Transparent background (real alpha). If that is impossible, use one flat plain white background.
- No grid lines, no borders, no frames, no numbers, no labels, no text, no shadows on the ground.

CELLS (left to right, top to bottom):
1. (row 1, column 1) a sleepy cat curled up, half-closed eyes, mid-yawn
2. (row 1, column 2) an open textbook in front of a small chalkboard with wavy lines, a drowsy aura
3. (row 1, column 3) a briefcase and a long meeting table with a ticking clock above, drowsy mood
4. (row 1, column 4) a microphone on a stand on a school stage podium, sleepy morning sun
5. (row 2, column 1) a retro radio playing soft music notes shaped like moons
6. (row 2, column 2) a cozy kotatsu table with a quilt and a bowl of mandarin oranges on top
7. (row 2, column 3) a small local train car in afternoon light, curtains half drawn
8. (row 2, column 4) three fluffy sheep in a row jumping over a little fence
9. (row 3, column 1) a crescent moon with a face, yawning widely
10. (row 3, column 2) a soft drowsy cloud front with a weather map curve and sleepy face
11. (row 3, column 3) a swirl galaxy with sleepy half-closed eyes in the center
12. (row 3, column 4) the whole universe shaped like an enormous yawning mouth full of stars
```
