# DESIGN.md — 『あくび、うつった。』 ゲームデザイン（骨子案 v0）

> ステータス：**骨子案**。数値はすべて初期案で、シミュレーター未検証。
> Phase 4 でシミュレーターを作ったあと、BALANCE.md の結果を見て調整する。

---

## 1. コンセプト

- **ひとことで**：あくびは見るとうつる。1つのあくびが部屋 → 町 → 星 → 銀河へ広がっていく。
- **増えるもの**：「あくび」（メイン通貨）。単位表示は「あくび」「あくび/秒」。
- **なぜ増えるのか**：あくびは伝染する。誰かがあくびをすると、それを見た誰かもあくびをする。
  だから「生産者が増えるほど、もっと速く増える」ことに理由がいらない。
- **トーン**：ほっこり、ゆるい、ちょっとシュール。誰も傷つかないユーモア。
  説明文は「眠気にまつわる、あるある」を宇宙規模まで真顔で拡大していく。
- **フック**：「何を増やすゲーム？」→「あくび」。一言で伝わり、一言で笑える。

## 2. 基本ループ

1. 画面左の大きな「ねむそうな顔」をクリック → あくび +1（クリック強化で増える）。
2. あくびを払って **生産者** を雇う（＝眠気をうつしてくれる存在）。
3. 生産者が毎秒あくびを生む → もっと高い生産者を買う。
4. アップグレードで倍率を上げる。ときどき **流れ星**（ランダムイベント）を拾う。
5. 伸びが鈍ったら **「おやすみ」**（第1プレステージ）で世界を寝かせ、**夢のかけら** を得てやり直す。

### 3.1 階層型生産「眠気の連鎖」（Phase 6a で実装）

- 解放後、**生産者 #k（k≥2）は毎秒、生産者 #k-1 を「うつす」**（＝無料で増やす）。
  - 例：「退屈な授業」が「眠そうな猫」を増やし、「長すぎる会議」が「退屈な授業」を増やす。
- 各生産者は **購入数** と **うつった数** を別々に持つ。
  - 価格計算には **購入数だけ** を使う（連鎖で価格が上がると気持ちよさが消えるため）。
  - 生産量には **購入数＋うつった数** を使う。
- 連鎖の強さ：`うつる数/秒 = 持っている数_k × 0.02`（`CHAIN.rate`）。うつった仲間もまたうつす。
- 解放は夢ツリーのノード「眠気の連鎖」（まどろみの枝、羊毛まくらの次・100 かけら）。
  「1周目は Cookie Clicker 型、数周目から AD 型に変わる」流れにする。シミュレーションでは能動 127分・ゆったり 317分で解放。
- 生産者リストには「＋○ うつった」と表示する。オフライン中も、生産と同じ効率で進む。

## 4. クリック

- 基本：1クリック = あくび 1。
- 強化：アップグレードで「+N」と「あくび/秒 の X% を加算」の2系統。
- クリック演出：顔があくびをして、周りに小さな「ふわぁ」が浮かぶ（エフェクトOFF設定あり）。
- キーボード：Space / Enter でクリックと同じ動作（連打対策で最大 20回/秒）。

## 6. プレステージ層

### 6.1 第1層「おやすみ」（夢のかけら）— Phase 4 で実装

- **意味づけ**：世界じゅうがあくびをしきったら、みんなでいったん眠る。眠った世界は **夢** を見る。
- **解放条件**：今回の周回の累計あくび ≥ **1.5億**。条件の 10% で「夢」タブを予告する。
- **獲得量**：`夢のかけら = floor( 10 × (1 + log10(今回の累計 / 1.5億))² × 獲得倍率 )`
  - 条件ちょうどで 10、10倍で 40、100倍で 90、1000倍で 160。
  - 当初案の「累計の 0.5 乗」や 1/3・1/4 乗では、かけらの受動ボーナスと組み合わさって
    周回ごとにかけらが倍々に増え続けた（BALANCE.md）。対数にして伸びをゆるめた。
- **効果（2つの使い道）**：
  1. **累計獲得数** に応じて、全生産 ×(1 + √累計のかけら × 10%)（使っても減らない。かけら100個で +100%）。
     当初は「1個 +1%」だったが、かけらに比例すると「おやすみラッシュ」が起きたため √ にした（§13・BALANCE.md）。
  2. 手持ちを消費して **夢ツリー** のノードを解放（永続）。
- **リセットされるもの**：あくび、生産者、アップグレード、流れ星の効果と次の流れ星までの時間、周回のプレイ時間・クリック数。
  **残るもの**：夢のかけら、夢ツリー、実績、全期間の記録、設定、改造フラグ、乱数のシード。
- **目標**：初回は 30〜60分。シミュレーションでは能動プレイ 31分・ゆったりプレイ 60分。

#### 夢ツリー（3系統・24ノード、§13 で採用）

| 入口 | 夢の入口（1：全生産 ×1.5） |
| まどろみ（生産） | ぬくぬく布団（3：×1.5）→ 猫の添い寝（8：猫10匹で開始）→ 授業の録音（40：授業5体で開始）→ 夢の残り香（200：1万あくびで開始）／ 深い眠り（15：×2）→ 羊毛まくら（60：実績1個 +1%）→ **眠気の連鎖**（100：§3.1）／ 熟睡のコツ（300：×3）→ 眠りの達人（1000：かけらのボーナス係数 +10%） |

### 6.2 第2層「冬眠」（ぬくもり・季節）— Phase 6b で実装

- **意味づけ**：何度眠っても眠り足りなくなったら、**冬眠** する。目覚めると季節がひとつ進んでいる。
- **解放条件**：夢ツリーを全部埋める（最後の「夢の交差点」を解放する）（§13）。
- **獲得**：ぬくもりの水準 = `floor(√(累計の夢のかけら / 1000))`。冬眠でもらえるのは、水準が **これまでの最高を超えたぶんだけ**。
  （毎回同じだけもらえる形では、ショップの倍率で夢ツリーを数十秒で埋め直して冬眠を繰り返せた。BALANCE.md）
  ぬくもりが0でも冬眠はできる（季節だけ進む）。これまでに得たぬくもり1つにつき全生産 +25%。
- **リセットされるもの**：夢のかけら（手持ち・累計）、夢ツリー（ぬくもりショップで残すものは除く）、あくび、仲間、まくら工房、流れ星の効果。
  **残るもの**：ぬくもり、ぬくもりショップ、実績、全期間の記録（おやすみの回数も）、羊図鑑・まくら、設定。
- **ぬくもりショップ**（冬眠しても残る。全部で 27 ぬくもり）：

| 品 | 値段 | 効果 |
|---|---|---|
| 夢への近道 | 1 | 夢の入口と3本の枝の1段目を残す |
| ゆたんぽ | 1 | 全生産 ×3 |
| 夢見がちな毛布 | 2 | 夢のかけらの獲得 ×2 |
| 星降る天窓 | 2 | 流れ星の尾・願いの瞬きを残す |
| 寝ぐせの目覚まし | 2 | オートおやすみ（§8） |
| てきぱき秘書 | 3 | 自動購入・自動で作るが10倍速い（§8） |
| 寝言の秘書 | 3 | 自動購入の3ノードを残す |
| 長い長い夜 | 3 | おやすみ中の3ノードを残す |

- **季節**（§13：遊び方のルールが変わる）：1回目の冬眠で春になり、冬眠のたびに 春→夏→秋→冬→春… と進む。冬眠する前は季節なし。

| 季節 | ルール |
|---|---|

| 🌻 夏 | おやすみ中の効率 +50%・上限 +4時間 |
| 🍁 秋 | まくら工房（アップグレード）が半額 |
| ⛄ 冬 | 仲間（生産者）の値段が2倍、そのかわり眠気の連鎖が3倍 |

- 画面上部に季節のバッジ（ルールは title で表示）。統計にも季節を出す。
- 冬眠すると **チャレンジ**（§7）が解放される。ショップには自動化の品もある（§8）。
- **目標**：初回は 数時間〜1日。シミュレーションでは能動 2.7時間・ゆったり 8.2時間、2回目以降は 1.5〜4時間おき（BALANCE.md）。

### 6.3 めざめ（エンディング）— Phase 8 で実装

- **意味づけ**：宇宙じゅうがあくびをしきったら、朝が来る。ゲームの「おしまい」の場面。
- **条件**（3つすべて）：眠れない夜（チャレンジ）を8つすべてクリア／冬眠 4回（季節がひとめぐり）／この周回の累計 **1e35** あくび。
  冬眠したことがあれば、冬眠のページに条件の一覧（✅/⬜）を出す。
- **めざめると**：エンディング（短い物語を1行ずつ）を流し、「朝日」で全生産 ×2（ずっと）。実績「おはよう」。
  **何もリセットしない**。そのあとも遊び続けられ、ボタンは「もう一度、朝の夢を見る」になる（一度きり）。
- **目標**：数日。シミュレーションでは能動プレイのボットが 14.0時間（冬眠4回目）で累計 1e35 に届く（チャレンジは1回目の冬眠のあとに全部クリアした扱い）。
  人は買い物の迷い・画面を見ていない時間・チャレンジに挑む時間があるので、1〜3日を見込む（BALANCE.md）。
- 第3の転生層（ぬくもりまでリセットする層）にはしなかった（§13）。

### 6.4 夢の続き（終わらない夢）— Phase 8 で実装

- 夢の交差点を解放すると、その横に出る **何度でも解放できるノード**。n 段階目の値段 = 10,000 × 3^(n-1) かけら、1段階ごとに全生産 ×2。
- 冬眠すると 0 段階に戻る（ショップでも残せない）。ツリーを埋めたあと、次のぬくもりまでの「かけらの使い道」にする。
- 5段階で実績「終わらない夢」。セーブで受け付けるのは 30段階まで（値段が安全な整数に収まる範囲）。

## 7. チャレンジ「眠れない夜」（Phase 6c で実装）

- 1回目の冬眠で解放。始めると今の周回がリセットされ（夢のかけらはもらえない）、制限つきで遊ぶ。
- この周回の累計あくびが目標に届いたらクリア（周回はそのまま続く）。報酬は永続。クリア済みはもう挑戦できない。
- 「やめる」・おやすみ・冬眠で挑戦は終わる（何ももらえない）。「一夜漬け」は 20分を過ぎたら失敗。
- 目標は、能動プレイのボットが1回目の冬眠の直後に挑んで 11〜28分でクリアできる値（BALANCE.md）。

| ID | 名前 | 制限 | 目標 | 報酬（永続） |
|---|---|---|---|---|
| `coffee` | コーヒー解禁 | 全生産 ×0.5 | 1e19 | クリック ×1.5 |
| `cats_only` | 猫しかいない | 雇えるのは #1〜#3 だけ | 1e9 | #1〜#3 の生産 ×3 |
| `all_nighter` | 徹夜明け | クリック無効（猫5匹から始める） | 1e19 | おやすみ中の効率 +10% |
| `cram` | 一夜漬け | 20分以内 | 1e19 | おやすみのあと 1億あくびで開始 |
| `insomnia` | 不眠症 | まくら工房が使えない | 1e16 | 全生産 ×2 |
| `alarms` | 目覚まし時計だらけ | 流れ星が出ない | 1e19 | 流れ星が 20% 早く来る |
| `rush_hour` | 満員電車 | 仲間の値段 ×10 | 1e19 | 仲間の値段 ×0.9 |

  徹夜明けは、クリックできないと最初の猫も買えず詰むので、猫5匹から始める。目標は「おやすみ前の累計」ではなく、シミュレーションで決めた。

## 8. 自動化（解放する楽しみ）

- **自動購入**（夢ツリー・寝言の枝）：生産者ごとに1秒に1体。生産者リストの見出しで ON/OFF。
- **自動で作る**（夢ツリー・自動まくら）：いちばん安いアップグレードを1秒に1つ。工房の見出しで ON/OFF。
- **オートおやすみ**（ぬくもりショップ「寝ぐせの目覚まし」・2）：得られる夢のかけらが累計のかけらの 25/50/100/200% 以上になったら自動でおやすみ。夢のページで ON/OFF と割合を選ぶ。
- **てきぱき秘書**（ぬくもりショップ・3）：自動購入・自動で作るが 10倍速い。
- 最初から全部は渡さない。夢ツリー → 冬眠のショップ、の順に解放される。

## 9. ランダムイベント「流れ星」

- 平均 3〜5分に1回、画面のどこかを 12秒間流れる。クリックすると次のどれかが起きる（重みは data に置く）。
  - **ねがいごと**：全生産 ×7、60秒
  - **ひとやすみ**：今の生産 15分ぶんを即時獲得（上限：所持あくびの 15%）
  - **大あくび**：クリック ×77、10秒
  - **羊が迷い込む**：羊を数えるのチケット +1（§10）
- 放置中は出現しない（能動プレイヤーだけが得をする）。
- 乱数はシード付き PRNG。出現時刻と結果はセーブ時点で決まっている（リロードで変わらない）。

## 10. ミニゲーム①「羊を数える」（Phase 5 で実装）

- **内容**：柵を跳び越える羊を、柵の上にいるとき（±0.18秒）に「数える！」（または Space キー）で数える。30秒。
  - 数える：ふつうの羊・ゆっくりの羊・めずらしい羊。
  - 数えない：黒い羊（⬛ の目印つき）・跳ぶふりをして引き返す羊。
  - 黒い羊や跳ぶふりの羊を数える、何もいないときに押す、はどれも「数え間違い」。連打は損になる。
  - スコア＝正しく数えた数 − 数え間違い（0 未満にしない）。
- **解放**：おやすみを1回する、または羊の群れ（#8）を1匹持つ。
  当初案は「羊の群れを持つ」だけだったが、シミュレーションでは1周目に羊まで届かないため、おやすみでも解放する。
- **費用**：チケット「まくら」1つ（20分で1つ回復・最大3つ。オフラインでも回復）＋ ふだんの毎秒生産 × 3分ぶんのあくび（最低100）。
  遊び始めた時点で費用を払ってすぐセーブする。途中でページを閉じた回は無効（払い戻さない）。
- **報酬**：90秒間 クリック ×(1 + 0.1 × スコア)、上限 ×6（大勝ちの上限）。
  めずらしい羊（金・雲・星・パジャマ・月の5種）を数えると **羊図鑑** に登録。1種類につき全生産 +2%。
- **期待値**：上手に数えて（スコア 15〜20）クリック ×2.5〜3 を90秒。クリックが毎秒生産の約2割の時期なら、
  増えるのは生産の約2〜3分ぶんで、費用（3分ぶん）とほぼ同じ。クリックの強い序盤はプラス寄り、自動化が進むとマイナス寄り（未シミュレーション）。
- **乱数**：羊の並びは、遊び始めたときに GameState のシードから決める（同じセーブから始めれば同じ並び）。
- **インターフェース**：`src/minigames/types.ts` の `{ id, unlockCondition, cost, start(), onFinish(result) }`。
  判定は `src/minigames/sheep/logic.ts`（画面のその場の反応と、終わったあとの判定で同じ関数を使う）。
- **流れ星「羊が迷い込む」**：まくら +1（満タンなら増えない）。ミニゲームを解放するまでは出ない。
- 2つ目：夢くじ（§16、Phase 8）。

## 11. 実績・オフライン・その他の数値

### 11.1 実績（60個以上）
- 分類：累計あくび／生産者の所持数／クリック数／流れ星／おやすみ回数／冬眠回数／チャレンジ／羊図鑑／隠し実績。
- ボーナス：実績1個につき全生産 +1%。
- 隠し実績の例：「寝落ち」（5分間なにも操作しない）、「夜更かし」（午前2〜4時にプレイ）、「数え間違い」（羊を数えるで黒い羊だけを数える）、「二度寝」（おやすみした直後の1分間、何もしない）。

### 11.2 オフライン進行
- **上限：8時間（初期）** ＝ ひと晩の睡眠時間。夢ツリーで最大 12時間まで延長できる。
  - 理由：寝る前に閉じて朝ひらく、というこのゲームらしい遊び方にちょうど合う。
    それ以上長くすると、毎日開く理由が弱くなる。
- **効率：50%（初期）**。夢ツリーとチャレンジ報酬で最大 100% まで上がる。
- 復帰時：「おやすみ中に ○○ あくびがうつりました」を表示する。
- 時計いじり対策：経過時間は 0〜上限 でクランプする。未来の時刻のセーブは整合性チェックで検出する。

### 11.3 数値表記
- デフォルトは日本語単位（万・億・兆・京…）。設定で英語略記と指数に切り替えられる。

## 16. ミニゲーム②「夢くじ」（Phase 8 で実装）

- **内容**：3つのリールに夢の絵柄が出る。気に入った絵柄を「残す」にして、ほかを **2回まで回し直せる**。最後に「これで決める」。
  いちばん多くそろった絵柄で報酬が決まる（羊を数えるは反射神経、夢くじは「どれを残すか」の判断）。
- **解放**：おやすみ 3回。**券**はおやすみ1回で1枚（最大3枚、オートおやすみでももらえる）。v11 からの移行では、これまでのおやすみの回数ぶん（最大3枚）。
- **絵柄と出やすさ**（`src/data/lottery.ts`）：月・星・羊・雲 が 2、布団・コーヒー が 1。

| 絵柄 | 3つそろい | 2つそろい |
|---|---|---|
| 🌙 月 | 10分間 生産 ×4 | 5分間 生産 ×2 |
| ⭐ 星 | 流れ星がすぐに流れる | 30秒間 クリック ×7 |
| 🐑 羊 | まくら +3 | まくら +1 |
| ☁️ 雲 | ふだんの生産 60分ぶん | 15分ぶん |
| 🛏️ 布団 | 今おやすみしたら得られるかけらの 50% | 10%（最低1個） |
| ☕ コーヒー | 60秒間 クリック ×20（「目が冴えた」） | 30秒間 クリック ×3 |
| そろわない | ふだんの生産 5分ぶん | |

- 生産の倍率・クリックの倍率は、夢くじどうしでは重ねずに置き換える。おやすみ・冬眠で消える（流れ星と同じ）。
- **乱数**：出目は、引いたときに GameState のシードから決める。回し直しで「残したリール」も記録してすぐセーブするので、
  リロードしても同じ出目・同じ残り回数から続く（結果を見てから引き直すことはできない）。
- **整合性チェック**：夢くじで増えるあくび・流れ星・まくら・かけらは、それぞれの上限に「この周回で引いた回数 × 1回の最大」を足す。
  券は おやすみ1回で1枚なので、「引いた回数＋手持ちの券 ≤ おやすみの回数」でなければ改造の疑い。
- 音：回すとき（`lotterySpin`）、そろったとき（`lotteryWin`）。隠し実績「目が冴えた」（コーヒーを3つそろえる）。
